Mengapa Nobar?

Nobar adalah ruang terbuka untuk karya video indie — dokumenter pendek, film eksperimental, video musik, dan animasi karya anak bangsa. Kami memutar setiap karya dari beberapa server cadangan agar bandwidth terbagi rata dan pemutaran tetap lancar bahkan saat server utama sedang padat.

  • Multi-server load balancing untuk stabilitas streaming.
  • Pemutaran langsung via iframe — tanpa download, tanpa iklan.
  • Profil kreator dengan tautan portofolio & sosial media.
